# Assignment 3 - UiPath Weather Automation ☀️

## Overview
This UiPath automation project demonstrates web scraping and data extraction from the AccuWeather website.

## Features
- Open browser and navigate to AccuWeather
- Search for city weather information
- Extract weather details (temperature, conditions)
- Display results in message box
- Input dialog for user city selection

## Workflow Steps
1. User inputs city name
2. Application searches on AccuWeather
3. Weather information is extracted
4. Results are displayed

## Technologies
- UiPath Studio 26.0+
- UI Automation Activities
- Web Scraping
